## 003-Write tests for both `src/calc/ops.py` and `src/calc/cli.py`

### Scope
- Write tests for the operations module `src/calc/ops.py`
- Write tests for the command-line interface module `src/calc/cli.py`
- This task does not cover the actual implementation of the modules
- This task does not cover writing the user interface, database, or frontend

### Acceptance Criteria
1. The tests for `src/calc/ops.py` should cover all basic arithmetic operations and edge cases
2. The tests for `src/calc/cli.py` should cover user input parsing and graceful handling of invalid input
3. The tests should be well-documented with docstrings

- 001-ops.md
- 002-cli.md
