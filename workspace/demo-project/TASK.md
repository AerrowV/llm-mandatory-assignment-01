# Task spec for the coding workers

Implement the two stub modules in `src/textmetrics/`. Each worker owns exactly

do not edit this file.

## Module 1 — `src/textmetrics/tokens.py` (worker 1)

Implement these four functions. The docstring on each stub is the specification;
keep the signatures exactly as given.

```python
def split_words(text: str) -> list[str]:
    """Lowercase, then split on any run of non-alphanumeric characters."""

def count_words(text: str, stopwords: set[str] | None = None) -> int:
    """Number of words after removing stopwords. Case-insensitive."""

def word_frequencies(text: str) -> dict[str, int]:
    """Counts per distinct word, lowercased, most frequent first."""

def top_n(text: str, n: int) -> list[tuple[str, int]]:
    """The n most frequent (word, count) pairs. Ties break alphabetically."""
```

Rules:

- `split_words("")` returns `[]`.
- Punctuation, underscores and digits count as separators. `"a,b_c1"` is three
  words, not one.
- `stopwords` are matched case-insensitively. Passing `None` removes nothing.
- `top_n` with `n <= 0` returns `[]`. Asking for more words than exist returns
  everything available.
- `word_frequencies` on empty input returns `{}`, never `None`.
